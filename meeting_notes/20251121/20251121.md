## 💭 팀 내 고민

- Reset 버튼 관련 함수 호출 누적 우려
  - Reset 버튼 클릭 시 `Controller.start()`가 매번 호출되어 스택에 함수가 계속 쌓일 수 있다는 우려가 제기됨.
  - 디버거를 활용하여 환인한 결과, `start()` 메서드는 즉시 실행 후 정상적으로 종료되기 때문에 호출 스택에 누적되지 않으며 메모리 누수나 성능 저하 문제도 발생하지 않음.
  - 즉, 이벤트 리스너는 계속 유지되지만, start() 호출은 한 번 실행 후 스택에서 사라지므로 안전한 구조임을 확인.
- 리스너(AppListener) 구조 개선 고민
  - 현재 `AppListener`가 여러 버튼의 이벤트를 한 곳에서 관리하는 구조로 되어 있음.
  - 구조적으로는 각 버튼별로 별도의 리스너 클래스를 분리하면 SRP에 더 적합하며 유지보수성과 가독성이 향상될 수 있다는 의견이 나옴.
  - 다만,
    - 현재 구현된 기능의 동작에는 문제가 없고,
    - 리스너 로직 복잡도가 낮아 파일 분리로 얻는 효용성이 상대적으로 작으며,
    - 프로젝트 기간이 종료된 상황에서 구조 개선을 위한 리팩토링을 진행할 경우 일정 지연 가능성이 있다고 판단.
  - 이에 따라 구조 분리 리팩토링은 보류하기로 결정함.
